01. IEC 61508 Safety Analyzer

Run static safety checks on your control variables in real time. The compiler evaluates logic paths to flag overlapping controls or missing fail-safes.

  • Conflict detection (conflicting outputs)
  • Emergency stop coverage validation
  • Automatic SIL scoring and diagnostics

02. Cross-Vendor Code Generation

Compile clean, address-mapped, and standards-compliant Structured Text (ST) ready for direct import into professional industrial IDEs.

  • CODESYS V3 compliance
  • Siemens TIA Portal source blocks
  • Rockwell Automation Studio 5000 compatible output
PROGRAM PLC_PRG
VAR_INPUT
  estop_active : BOOL;
END_VAR
VAR_OUTPUT
  conveyor_enable : BOOL;
END_VAR
IF estop_active THEN
  conveyor_enable := FALSE;
ELSE
  conveyor_enable := TRUE;
END_IF;
END_PROGRAM

ATLAS implements an annotation-driven safety engine that validates code against critical industrial standards:

✓
Conflicting Outputs

Detects rules that could drive an output to opposite states simultaneously.

✓
Missing ELSE Paths

Ensures every conditional assignment has a defined safe-state fallback.

✓
E-Stop Coverage

Validates that @CRITICAL outputs are protected by @ESTOP logic.

✓
Circular Dependencies

Prevents logic loops that could cause jitter or non-deterministic behavior.
