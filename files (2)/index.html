Rung 01 — from DSL to plant floor

One rule.
Three readable forms.

This is the exact source language ATLAS accepts — no pseudocode. A single interlock rule, compiled straight to IEC 61131-3 Structured Text.

source.dslATLAS DSL
# Rule 1: Motor control with timer delay (5 seconds)
IF switch = ON FOR 5 SECONDS THEN motor = ON ELSE motor = OFF END

# Rule 7: Emergency stop — all off if e_stop is triggered
IF e_stop = ON THEN motor = OFF ELSE motor = ON END
→
output.st--target siemens --format st
// Auto-generated Structured Text
IF switch AND t_switch.Q THEN
    motor := TRUE;
ELSE
    motor := FALSE;
END_IF;

IF e_stop THEN
    motor := FALSE;
ELSE
    motor := TRUE;
END_IF;

Swap --target and the same source compiles for CODESYS or Rockwell instead — or emits PLCopen XML for interchange.

Module — capability

Built for the whole path from
rule to certified artifact.

01

Three vendor targets

One source compiles to Siemens TIA Portal, CODESYS V3, or Rockwell Studio 5000 — plus vendor-to-vendor ST translation via --translate-from / --translate-to.

02

IEC 61508 safety analysis

The safety engine checks for rule conflicts, missing safe-state paths, and e-stop coverage, and can gate a build on a minimum SIL level with --min-sil.

03

Diagnostics & code quality

Maintainability and lint-style checks run with --diagnostics, reporting in text, JSON, Markdown, or HTML for CI pipelines.

04

Multilingual DSL

Core logic keywords have aliases in Spanish, Hindi, and Arabic — SI … ENTONCES … SINO … FIN compiles identically to IF … THEN … ELSE … END.

05

Ten deployment CPU profiles

x86_64/x86, ARMv7/AArch64, RISC-V RV32/RV64, PowerPC64, MIPS32/64, SPARC64, and a WASM32 metadata profile — used for manifests and reproducible-build evidence.

06

Integrity & security

SHA-256 source and output hashing, an expected-hash gate, path sandboxing, and resource limits on tokens, AST nodes, and symbols.

Rung 03 — the --industrial pack

One flag. A thirty-control
evidence pack.

--industrial applies paranoid hardening plus safety, diagnostics, deterministic output, and no-overwrite gates in a single pass.

INTEGRITY

Source & output hashing

SHA-256 on source and output, constant-time hash compare, an expected-source-hash gate, and bounded/binary-safe source reads.

SANDBOX

Path & resource limits

Path control-character rejection, sandbox path mode, parent-traversal and absolute-path rejection, symlink output rejection, and token/AST-node/symbol limits.

WRITE SAFETY

Atomic, checked output

Atomic temp-file writes, output-overwrite refusal, write-error checking, and deterministic timestamps for reproducible builds.

SAFETY GATES

Fail before it ships

Strict warning gate, safety-critical gate, minimum-SIL gate, required-e-stop gate, and required-ELSE (safe-state) gate.

EVIDENCE

Audit-ready reports

Diagnostics quality score, IEC 61508 safety report, resource-limit manifest, vendor-target manifest, CPU-profile manifest, and machine-readable JSON evidence.
